# App de agendamento para consultório · demo

**Teste no navegador:** https://deborahdalonso.github.io/clinic-booking-demo/

App em React Native (Expo) para consultório odontológico: a paciente marca, remarca e cancela consultas,
e a clínica acompanha a agenda do dia, registra faltas e vê o previsto da semana.

No computador o app aparece dentro de um celular; no celular abre em tela cheia. Os dados ficam só no
navegador de quem testa.

Consultório, nomes e preços fictícios.

Desenvolvido por [Deborah Dalonso](https://www.linkedin.com/in/deborah-dalonso-482099138).
